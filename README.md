Arduino-based beginner embedded systems project.

**Goal**

Build a small desk device that detects when an object approaches and reacts using physical outputs such as an LED, buzzer, and servo motor.

**Planned Features**

- Distance detection with an ultrasonic sensor
- LED feedback
- Buzzer feedback
- Servo motor movement
- Simple interaction logic

**Hardware**

- Arduino Uno-compatible board
- Breadboard
- Ultrasonic distance sensor
- LED
- Buzzer
- Servo motor
- Resistors and jumper wires

**Current Status**

Work in progress.

Currently learning and testing:

- Digital input/output
- Push buttons
- LEDs
- Pull-down resistors
- Basic Arduino C/C++

**Future Improvements**

- More advanced interaction behavior
- Enclosure / physical design
- Additional sensors
- Improved software structure
